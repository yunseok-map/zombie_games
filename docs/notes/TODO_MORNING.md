## 0. 먼저 5분: 밤새 뭐가 바뀌었는지 눈으로 확인

```
npm run dev
```
브라우저에서 시작 → **1F → B1 → 2F → 3F → 옥상** 순으로 이어진다.
빨리 확인하려면 개발자 콘솔(F12)에 아래를 붙여넣어 구역을 건너뛴다.

```js
game._nextStage()          // 다음 구역으로. 4번 부르면 옥상
```

바뀐 것 다섯 가지만 보면 된다.
1. **시작 화면**이 검은 배경이 아니라 실제 복도다. 손전등이 훑고 먼지가 떠다닌다
2. 손에 든 무기가 **텍스처 있는 쇠파이프**다 (전에는 절차적 원통)
3. 병실에 **진짜 병상·링거대·커튼**이 있고, 금속이 빛을 받아 형태가 읽힌다
4. 2F·3F·옥상이 생겼고 각 구역에 사건이 있다. 옥상에서 90초 버티면 **EXTRACTED**
5. **포복체**(기어다니는 좀비)가 섞여 나온다 — 낮아서 늦게 보인다

배치를 바꿨다면 브라우저 콘솔(F12)에 아래를 붙여넣어 자동 검사를 돌린다.
```js
const { runQA, summarize } = await import('/tools/qa_stages.js');
console.log(summarize(runQA(window.game)));
```
구역마다 25항목(총 125)을 검사한다. 지금은 전부 통과 상태다.

## 2. 실제로 플레이해서 밸런스 체감 (약 40분)

**이건 반드시 사람이 해야 한다.** 숫자로는 "어렵다"를 알 수 없다.
2~3판 돌려 보고 아래 표에 느낌을 적은 뒤, 값만 바꾸면 된다.
**`src/config/balance.js` 하나만 열면 된다. 다른 파일은 건드리지 않는다.**

| 느낌 | 고칠 값 |
|---|---|
| 좀비가 너무 빨리/느리게 몰린다 | `DIRECTOR` 의 스폰 간격·긴장도 |
| 배터리가 너무 빨리/늦게 닳는다 | `FLASHLIGHT.drainPerSec` |
| 근접이 너무 약하다/세다 | `weapons.js` 의 `damage` · `cooldown` |
| 좀비가 너무 질기다 | `ZOMBIE.shambler.hp` |
| 복도가 너무 어둡다/밝다 | 각 구역 파일의 `meta.mood.ambientIntensity` |

> **한 번에 한 값만 바꾸고 다시 플레이한다.** 두 개를 같이 바꾸면 뭐가 효과였는지 모른다.

체감 메모를 남겨 두면 다음 세션에서 AI 가 이어서 조정할 수 있다.

## 3. 구역별 "사건" — **구현해 뒀다. 플레이해 보고 판단만** (약 20분)

세 구역 모두 사건을 넣었다. 값은 전부 `balance.js` 의 `EVENTS` 에 있다.

| 구역 | 사건 | 판단할 것 |
|---|---|---|
| 2F 병동 | 병실 4곳의 **무전기**를 켜야 계단실이 열린다. 켤 때마다 소음 → 웨이브 | 4개가 너무 많은가? |
| 3F 수술부 | 수술실 2곳의 **무영등 전원**을 넣어야 봉쇄문이 풀린다. 켜면 방이 환해진다 | 환해지는 게 오히려 안 무서운가? |
| 옥상 | **신호탄**을 쏘고 헬기가 올 때까지 **90초 버틴다** (15초마다 웨이브, 마지막에 10마리) | 90초가 너무 길거나 짧은가? |

**옥상만 미리 재 뒀다** (2026-08-05 오전). 이것만 알고 플레이하면 판단이 쉬워진다.
- 예정 웨이브는 35마리지만 **실제로는 45~65마리가 나온다.** 웨이브가 올 때마다 Director 가
  목표치까지 따로 채우기 때문이다. "5마리씩 6번" 이라고 생각하고 값을 정하면 어긋난다.
- 총알만으로는 못 버틴다 — 한 판에 모을 수 있는 탄약 전량(98발)이 필요 피해량과 비슷하다.
  **근접이 절반을 책임지게 설계돼 있다.** 그게 싫으면 `holdSeconds` 를 줄이는 쪽이 낫다.
- 어제까지는 탄약 보급이 아예 없어서(48발이 전부) 이 구간이 수치상 불가능했다. **오늘 고쳤다** —
  수색하면 9mm 가 나온다. 그래서 어제 플레이한 느낌은 참고하지 마라.

- 마음에 안 들면 `EVENTS` 의 숫자만 바꾸면 된다 (`radioCount` · `lampCount` · `holdSeconds` 등).
- 사건 자체를 바꾸고 싶으면 어떻게 바꿀지만 적어 두면 다음 세션에서 AI 가 교체한다.
- **옥상 90초가 이 게임의 클라이맥스다.** 여기 난이도만큼은 직접 플레이해서 정해야 한다.

## 5. 플레이 영상 — **제출물 2번. 30~60초** (약 40분)

포인터락 때문에 자동 촬영이 안 된다. 직접 플레이하며 녹화해야 한다.

- **길이 30~60초. 규정이다.** 넘기지 마라. 90초짜리를 만들면 다시 잘라야 한다.
- **실제 플레이 화면 그대로**여야 한다. AI 합성·연출 편집·타인 영상 사용 불가.
  컷 편집(장면 이어붙이기)은 괜찮지만, 없는 장면을 만들어 넣으면 안 된다.
- 60초 배분 제안: 어두운 복도·손전등(8초) → 좀비 조우·근접(12초) →
  B1 완전 암흑·레버(12초) → 2F 점멸 복도(10초) → 옥상 버티기·EXTRACTED(18초)
- **소리를 반드시 켜고 녹화한다.** 이 게임은 소리가 절반이다.
- 녹화는 Windows `Win+Alt+R` (Xbox Game Bar) 로 충분하다.
- **YouTube 에 올리고 공개 또는 링크 공개로 둔다.** 비공개면 심사자가 못 본다.

> **커밋 기록 자체가 이 문서의 근거다.** 규정이 커밋 기록 유지를 요구하는 이유이기도 하다.
