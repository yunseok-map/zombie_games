## Phase 1 — 문과 명패

병실 입구가 뚫린 구멍이라 복도가 상자처럼 보인다. 문이 생기면 즉시 병동이 된다.

- [x] 1-1 문틀 — 상인방 + 양쪽 기둥
- [x] 1-2 문짝 12개 — 방마다 열림 각도를 다르게 (활짝 / 반쯤 / 거의 닫힘)
- [x] 1-3 문 유리창 — 병원 문 특유의 세로 직사각 창
- [x] 1-4 명패 텍스처 — 12종을 1024 아틀라스 한 장에 (PIL + 맑은고딕)
- [x] 1-5 명패 메시 — 문 옆 벽. UV 로 아틀라스의 각 칸을 참조

**복도 z=34.5 가 사실상 막혀 있었다.** 장애물 폭 2.2m 에 복도 내폭 3.8m 라

> 이 값이 최소 0.3m 는 남아야 한다.

## 별건 E — 3차 수정분

- [x] **공중부양 기어오기 수정** — `scream` 클립 후보에 `standing_up` 이 들어 있었다.
      엎드린 자세를 골반 높이 이동으로 표현하는 클립인데, 변환 때 루트 이동을 전부
      지웠기 때문에 골반이 선 높이에 고정된 채 눕는 포즈가 되어 공중에 떴다.
      → **`standing_up` / `crawl` 계열은 클립 후보에 넣지 마라.** 쓰려면 변환 시
      수직 루트 이동은 남겨야 한다.
- [x] **바닥 재질별 발소리** — 콘크리트 4 / 타일 4 / 잔해 3 / 젖은바닥 2 (ElevenLabs)
      스테이지가 `surfaceAt(x, z)` 를 내보내고 `Player._footsteps` 가 그걸 본다.
      복도·로비 콘크리트 · 병실 타일 · 천장 붕괴 지점 잔해 · 큰 핏자국 위 젖은 소리.
- [x] **걷기/달리기/앉기 음색 분리** — 재생속도로 구분 (달리면 0.88배로 무겁게,
      앉으면 1.1배로 가볍게). 파일을 늘리지 않고 체감을 만든다.
- [x] **소품 재질에 마모 표현** — 완전히 매끈한 재질은 플라스틱처럼 보인다.
      벽의 normal/roughness 맵을 낮은 세기로 재사용해 도장 벗겨짐·마모로 읽히게 했다.
      텍스처는 안 늘어난다.
